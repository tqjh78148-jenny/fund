# 台灣基金 ‧ 主動/被動 ETF 價格位階與大盤情境決策系統

> 每日自動同步最新淨值、價格位階判定（🟢 甜甜價 / 🟡 合理價 / 🔴 昂貴價）與大盤指數 (44k -> 50k~55k) 聯動目標價模擬器。

## 🌟 核心特色
1. **價格位階自動檢測**：
   - 根據歷史高點（Peak）計算回檔幅度（Drawdown %）與檢測跌破發行面額。
   - 自動判定【🟢 甜甜價】、【🟡 合理價】、【🔴 昂貴價】，並展示視覺化三色安全邊際儀表。
2. **大盤情境模擬器 (Market Scenario Simulator)**：
   - 基準大盤指數（44,000 點）至目標點數（50,000、51,000、52,000、55,000、60,000 點）。
   - 支援依「投資本金（萬元）」或「持有張數（張）」精算預期獲利。
   - 標的彈性 Beta 係數動態微調（純科技 1.8、權值成長 1.3、Covered Call 0.5、被動市值 1.0、高股息 0.75）。
3. **11 檔核心監控標的**：
   - **共同基金**：安聯台灣科技基金、統一奔騰基金、統一黑馬基金
   - **主動式 ETF**：00992A（主動群益台灣科技創新）、00981A（主動統一台股增長）、00406A（主動中信台灣收益）、00403A（主動統一升級50）
   - **被動/高股息 ETF**：0050、0056、00878、00919
4. **官方直達**：
   - 每檔標的均提供發行投信官方網站直達連結與證交所/基富通觀測平台連結。

## 🚀 快速開始

### 1. 本地直接開啟
直接以瀏覽器開啟 `index.html` 即可完整體驗所有互動試算與篩選功能。

### 2. 手動更新每日淨值與位階
執行更新腳本：
```bash
python update_fund_data.py
```
或雙擊執行 `run_daily_update.bat`。

## 🌐 部署為 GitHub Pages 免費網站
1. 在 GitHub 建立一個公開儲存庫（Repository），例如 `taiwan-fund-dashboard`。
2. 將此專案所有檔案上傳至儲存庫。
3. 前往儲存庫的 **Settings** -> **Pages**。
4. 在 **Build and deployment** 下的 **Branch** 選擇 `main` 分支並按 **Save**。
5. 稍等約 1 分鐘，即可獲得免費的線上專屬網址：`https://<你的GitHub帳號>.github.io/taiwan-fund-dashboard/`！
