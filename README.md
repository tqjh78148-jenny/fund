# 台股科技 ETF 與高科技佔比基金——價格位階評估暨 50,000 點推估系統

> 專為台股科技 ETF 與高科技佔比共同基金打造之價格位階評估與大盤 50,000 點目標價推估系統。全站介面嚴格遵循無表格規範，100% 採用結構化卡片、分項條列清單與標籤呈現。

## 🌟 核心特色
* **雙重量化指標演算法**：
  * 模型 A（波段高點回檔法）：回檔 25% 算甜（≥30% 極甜）、15%~20% 合理、<10% 昂貴。
  * 模型 B（均線負乖離法）：以 60MA 季線為主（≤ -10% 算甜）、120MA 半年線為輔（≤ -12% 算甜）。
  * 綜合燈號：💎 雙重甜甜價、🟡 偏甜/合理、🔴 昂貴過熱。
* **高科技專屬 Beta 乘數（1.6 ～ 2.0）**：
  * 純科技旗艦高彈性設定（安聯台灣科技、統一奔騰、00992A、0052 等 Beta 1.8），大盤 50,000 點推估更具實戰參考性。
* **大盤 50,000 點連動推估**：
  * 即時計算目標點位漲幅、標的預估目標價，以及每投入 10 萬元預估獲利金額。
* **動態新增標的**：
  * 支援直接在網頁介面輸入代碼與報價，動態加入追蹤卡片。

## 🚀 快速開始

### 1. 本地開啟
直接以瀏覽器開啟 `index.html` 即可使用。

### 2. 手動更新行情與位階
執行更新腳本：
```bash
python update_fund_data.py
```

## 🌐 部署至 GitHub Pages 免費網站
1. 在 GitHub 建立公開儲存庫（Repository），例如 `taiwan-tech-fund-50k`。
2. 上傳核心檔案（`index.html`、`taiwan_bank_funds.json`、`update_fund_data.py`、`README.md`、`.github`）。
3. 前往儲存庫 **Settings** -> **Pages**。
4. 在 **Branch** 選擇 `main` 並按 **Save**。
5. 稍候約 1 分鐘，即可獲得線上專屬網址：`https://<你的GitHub帳號>.github.io/taiwan-tech-fund-50k/`！
